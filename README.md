# Smart Bookmark App

Smart Bookmark App is a modern web application built using Next.js and Supabase.  
It allows users to securely log in with Google and manage their personal bookmarks in a clean and professional interface.

## Features

- Google OAuth Authentication
- Add new bookmarks
- View saved bookmarks
- Delete bookmarks
- Secure user-based data access using Row Level Security
- Responsive and modern UI

## Tech Stack

- Next.js
- Supabase (Database & Authentication)
- Tailwind CSS
- Vercel (Deployment)
